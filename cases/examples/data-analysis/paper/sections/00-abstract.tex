\paperexample{每个数字都必须能在案例的关键数字溯源表里追到来源；追不到的不许写进摘要。
正文与摘要一律用 3--4 位有效数字。表述强度必须与证据匹配：可行解 / 当前最好 /
给定假设下最优 / 全局最优；关联 / 预测贡献 / 因果。把启发式结果写成「最优」是丢分最快的方式。}
