# 三个通用能力演示

这些演示不对应任何历年具体题目，只展示工作台如何从一个简报进入首个 baseline、
候选路线、Champion/Challenger 和最低数值检查。

```bash
python3 cases/examples/optimization/experiments/code/run_demo.py
python3 cases/examples/data-analysis/experiments/code/run_demo.py
python3 cases/examples/hybrid/experiments/code/run_demo.py
make demos
```

每个演示都可以复制成新的 `cases/<case_id>/`；队员只需先重写 `case_brief.md` 和
题面输入，模型池与实验板再随题目调整。
