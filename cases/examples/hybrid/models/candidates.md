# 混合建模候选路线池

## M-01：点预测—确定性优化

- 方法族：forecast-then-optimize
- 核心思想：将点预测直接作为需求参数，求解简单成本决策
- 优势：接口清楚、容易做 baseline
- 风险：忽略预测误差
- 最便宜的证伪实验：需求在预测值上下扰动时复算成本和容量
- 规格：`SPEC-P2-M01-probe` → `SPEC-P2-M01`（MATLAB 主实现 + Python 复算）
- 状态：`champion`

## M-02：情景/鲁棒决策

- 方法族：scenario or robust optimization
- 核心思想：让多个需求情景共同影响备货量
- 优势：显式处理误差和服务水平
- 风险：情景概率或鲁棒半径的假设
- 最便宜的证伪实验：两情景手算决策与 M-01 对照
- 状态：`challenger`

## M-03：分位数预测—服务水平决策

- 方法族：quantile forecasting plus service constraint
- 核心思想：用需求分位数控制缺货概率，再进入库存决策
- 优势：预测不确定性可以直接解释
- 风险：分位数校准和样本量不足
- 最便宜的证伪实验：比较不同分位数下的成本—服务曲线
- 状态：`candidate`

## 为什么 Challenger 是 M-02

M-01 的失效模式是「点预测不够准」。M-02（情景/鲁棒）显式处理误差，完全不依赖点预测
精度，因此构成真正的保险；M-03（分位数预测）仍然建立在上游预测可用之上，与 M-01
共享同一失效模式，做不了备份。
