# 预测驱动库存决策 轻测试（probe）

## 1. 要证伪的假设

「点预测足够好，把预测值直接代入确定性库存模型就能得到稳健的备货量。」如果需求偏离
预测时成本急剧恶化，这条两阶段路线就需要换成场景/鲁棒版本（M-02）。

## 2. 判据

- 通过：在需求 6/8/10 三个场景下，按点预测 8 求得的备货量所产生的成本，最大值不超过
  最优成本的 2.5 倍。
- 失败：任一场景成本超过最优成本的 2.5 倍，或备货量违反容量约束。

## 3. 最小实例 / 最小样本

- 规模：单期、单品，容量 10 units。
- 来源：手工构造。
- 构造方式：持有成本 1、缺货惩罚 5、点预测需求 8、扰动场景 {6, 8, 10}。
- 真值来源：容量范围内枚举 0–10，可手算核对。

## 4. 实现要点

- 输入：上述常量。
- 核心步骤：
  1. 对 q = 0…10 计算 cost(q) = q·1 + max(8 − q, 0)·5；
  2. 取最小成本对应的 q；
  3. 固定该 q，在需求 6/8/10 上重新计算成本。
- 输出：最优 q、对应成本、三个场景成本。
- 随机种子：`rng(42, 'twister')`（本 probe 不涉及随机，仍固定以保持一致）。
