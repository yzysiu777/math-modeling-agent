# Evidence-calibrated language reference

Use a claim only after identifying its evidence type:

| Evidence type | Safe wording |
|---|---|
| Definition or input | “题面给出”“数据中记录” |
| Mathematical derivation | “由式……可得”“在假设……下” |
| Deterministic computation | “计算得到”“在该输入下” |
| Empirical experiment | “在指定切分/重复实验中观察到” |
| Association | “呈相关/关联”“在预测模型中重要” |
| Heuristic optimization | “得到可行/较优解”“当前算例中” |
| Solver certificate | “求解器在该模型和参数下返回最优性证书” |
| Unverified idea | “候选方案”“尚待验证” |

Never strengthen a claim merely because two models agree. The paper must point to a source, derivation, executable test, experiment, or explicit human decision.
