# 混合建模实战方法卡

混合题先写清“上游输出 → 下游输入”的字段、类型、单位、时间语义和误差规则，再
比较决策价值。实验记录聚焦输入、配置、结果和下一步。

## Predict-then-optimize

- 适用信号：上游预测需求、价格、到达量或风险，下游据此做库存、分配、排程或路径决策。
- 核心变量或对象：预测 \(\hat\theta\)、决策 \(x\)、目标 \(f(x,\hat\theta)\) 和接口字段。
- 基本数学形式：先拟合 \(\hat\theta=g(z)\)，再求 \(x^\star(\hat\theta)\in\arg\min_x f(x,\hat\theta)\)。
- 最小 baseline：常数/朴素预测 + 确定性小规模优化。
- 最便宜的证伪实验：对 \(\hat\theta\) 做上下扰动，观察下游可行性、成本和决策变化。
- 与哪些方法公平比较：端到端简单决策、不同预测器和同一优化器使用相同时间截点与场景。
- 常见失败模式：预测使用未来信息、单位/时间窗不一致、下游悄悄改变目标、只看预测误差不看决策损失。
- 论文中可以声称什么：在指定预测接口和下游模型下的决策表现及误差敏感性。
- 论文中不能直接声称什么：预测最准确必然决策最好，或上游相关性直接产生下游因果效果。

## 情景优化

- 适用信号：未来参数有若干代表性情景、样本场景或离散风险状态。
- 核心变量或对象：场景 \(\xi_s\)、概率 \(p_s\)、共享决策 \(x\)、场景响应 \(y_s\) 和风险指标。
- 基本数学形式：最小化 \(\sum_s p_s f(x,\xi_s)\)，或加入机会约束、CVaR 与场景可行性。
- 最小 baseline：均值预测 + 确定性优化，并对相同场景事后评估。
- 最便宜的证伪实验：两个极端场景和一个中性场景的手算成本—服务比较。
- 与哪些方法公平比较：相同场景集、概率、共享约束、风险指标和计算预算。
- 常见失败模式：场景重复或概率不归一、场景生成看到了测试结果、只展示有利场景。
- 论文中可以声称什么：在给定场景集合/概率和风险定义下的期望或场景表现。
- 论文中不能直接声称什么：有限场景覆盖所有未来，或场景外仍有保证。

## 鲁棒决策

- 适用信号：预测误差边界比概率分布更可信，且最坏情形可接受性比平均收益重要。
- 核心变量或对象：不确定集合 \(\mathcal U\)、先验决策 \(x\)、扰动 \(\xi\) 和最坏损失。
- 基本数学形式：\(\min_x\max_{\xi\in\mathcal U}f(x,\xi)\)，或要求对所有 \(\xi\in\mathcal U\) 满足约束。
- 最小 baseline：点预测确定性决策 + 边界压力测试。
- 最便宜的证伪实验：扩大/缩小不确定半径，观察目标、可行性和保守程度。
- 与哪些方法公平比较：相同扰动集合、预算、约束和服务指标下对比确定性及情景方法。
- 常见失败模式：集合随结果调参、最坏场景不现实、过度保守导致资源浪费、未报告名义场景表现。
- 论文中可以声称什么：对声明集合内扰动的可行性或最坏目标界。
- 论文中不能直接声称什么：对集合外扰动稳健，或鲁棒方案在平均意义下一定更优。

## 分位数 / 服务水平决策

- 适用信号：缺货、延迟、漏检等代价不对称，业务更关心达到某个服务概率。
- 核心变量或对象：条件分位数 \(q_\tau(z)\)、服务水平 \(\tau\)、决策 \(x\) 和缺口/违约指标。
- 基本数学形式：最小化 pinball loss 估计 \(q_\tau\)，下游约束 \(P(\text{需求}\le x)\ge\tau\) 或用经验服务率替代。
- 最小 baseline：均值预测 + 固定安全系数或历史分位数。
- 最便宜的证伪实验：比较多个 \(\tau\) 的成本—服务曲线，并在留出数据校准覆盖率。
- 与哪些方法公平比较：相同服务指标、预测窗口、成本参数和留出集。
- 常见失败模式：未校准分位数被当成概率、样本量不足、服务率只在训练期报告。
- 论文中可以声称什么：指定样本和目标水平下的经验成本—服务权衡。
- 论文中不能直接声称什么：分位数预测保证任意未来期服务水平，或把名义 \(\tau\) 当现实覆盖。

## 上游误差传播

- 适用信号：预测/估计误差会改变下游约束、目标、资源使用或风险排名。
- 核心变量或对象：误差 \(e=\hat\theta-\theta\)、决策映射 \(x(\hat\theta)\)、可行性指标和损失差。
- 基本数学形式：比较 \(f(x(\hat\theta),\theta)-f(x(\theta),\theta)\)，并记录扰动到约束余量的传播。
- 最小 baseline：点预测下游解 + 固定比例上下扰动。
- 最便宜的证伪实验：对关键上游字段做单变量和联合扰动，记录目标、服务、违约和决策变化。
- 与哪些方法公平比较：相同误差样本/场景、扰动范围、下游求解器和评估指标。
- 常见失败模式：只报告预测 MAE、不测决策损失；误差方向被截断；不可行解被静默修复。
- 论文中可以声称什么：在指定误差范围或场景下的敏感性、风险和脆弱接口。
- 论文中不能直接声称什么：预测误差小就足以保证决策稳定，或一次扰动实验覆盖所有联合误差。

## 端到端与分模块 baseline 比较

- 适用信号：需要判断“先预测再优化”是否值得，或端到端目标能否改善最终决策。
- 核心变量或对象：上游模块 \(g\)、下游模块 \(h\)、端到端损失 \(L(h(g(z)),y)\) 和分模块指标。
- 基本数学形式：比较模块串联 \(x=h(g(z))\) 与直接决策器 \(x=k(z)\)，同时保留预测误差和决策损失。
- 最小 baseline：历史规则/常数决策，或点预测 + 简单优化器。
- 最便宜的证伪实验：在同一留出场景上比较预测指标、可行率、决策目标和运行成本。
- 与哪些方法公平比较：相同输入信息、时间截点、场景、资源预算和下游约束。
- 常见失败模式：端到端使用了额外未来字段、模块接口未冻结、只挑有利指标、无法解释错误来源。
- 论文中可以声称什么：在指定接口和评价协议下的整体决策收益及模块误差贡献。
- 论文中不能直接声称什么：端到端一定更先进，或模块指标提升必然转化为决策收益。
