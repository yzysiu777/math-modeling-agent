# 运筹优化检查清单

- [ ] 目标、决策变量、索引集合、变量类型、单位和边界完整
- [ ] 每条题面硬约束均有公式和代码位置
- [ ] 初始状态、终止状态、守恒、容量和时序约束已检查
- [ ] 小规模手算/穷举结果与实现一致
- [ ] 至少有简单 baseline 和公平对照
- [ ] 验证四件套齐全：独立复算、变异注入（错位/移位后必须判 FAIL）、异族互证、参数敏感性
- [ ] 每个输出解通过独立可行性检查
- [ ] 目标值由独立程序或直接公式复算
- [ ] 求解器状态、容差、随机种子、停止条件、gap 与下界已记录
- [ ] 清楚区分可行、较优、当前算法最好和全局最优
- [ ] 多目标权重、归一化、Pareto 或风险偏好有敏感性分析
- [ ] 极端、不可行、边界和规模增长测试已运行
- [ ] 失败路线和局部最优风险已记录
