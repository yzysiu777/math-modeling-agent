# 数据分析实战方法卡

这些卡片帮助 Agent 快速形成不同的数据分析路线。先固定实体粒度、标签、时间边界、
切分和指标，再比较模型；方法卡不能替代对真实数据和实验结果的检查。

## 描述统计 / 朴素预测 baseline

- 适用信号：样本少、需要先了解分布，或尚未证明复杂特征有增量价值。
- 核心变量或对象：实体/时间粒度、均值/中位数、分位数、频数、最后观测值和基准误差。
- 基本数学形式：预测均值 \(\hat y=\bar y_{\mathrm{train}}\)、最后值 \(\hat y_t=y_{t-1}\) 或经验比例。
- 最小 baseline：训练集均值/中位数、多数类或 seasonal-naive（若有周期）。
- 最便宜的证伪实验：固定留出集，比较朴素预测与简单趋势，检查复杂模型是否有实际增益。
- 与哪些方法公平比较：线性模型、树模型或时序模型使用相同切分、指标和预测窗口。
- 常见失败模式：均值跨实体混用、把测试期信息算入 baseline、类别比例随时间漂移却未说明。
- 论文中可以声称什么：在指定切分上的基准表现、分布差异和误差尺度。
- 论文中不能直接声称什么：基准表现代表真实因果机制，或复杂模型没有提升就证明变量无效。

## 线性 / 广义线性模型（GLM）

- 适用信号：需要可解释系数，响应与特征关系近似线性，或计数/二分类适合相应链接函数。
- 核心变量或对象：设计矩阵 \(X\)、响应 \(y\)、系数 β、链接函数 \(g(\mathbb E[y|X])=Xβ\)。
- 基本数学形式：线性回归 \(y=Xβ+\varepsilon\)；Logistic 为 \(\logit(p)=Xβ\)，计数可用 Poisson/负二项。
- 最小 baseline：均值、常数概率或单变量模型。
- 最便宜的证伪实验：固定切分比较残差、校准和系数符号，检查非线性/异方差/过度离散。
- 与哪些方法公平比较：树模型、正则化线性模型和时序模型使用同一特征可用范围和验证方式。
- 常见失败模式：共线性、标签泄漏、链接函数不匹配、把相关系数或系数解释成因果效应。
- 论文中可以声称什么：在模型假设和控制变量范围内的关联、预测或估计结果。
- 论文中不能直接声称什么：未经设计支持的因果关系、超出训练范围的线性外推或统计显著即业务重要。

## 树模型 / 集成模型

- 适用信号：特征关系非线性、有阈值/交互，或需要较少手工变换的强预测 baseline。
- 核心变量或对象：样本特征 \(x\)、分裂规则、树集合、预测 \(\hat y=\frac1B\sum_b T_b(x)\)。
- 基本数学形式：递归划分输入空间，以损失下降选择分裂；随机森林、梯度提升或 XGBoost 可作为候选。
- 最小 baseline：浅层单树或线性模型，限制深度和迭代次数。
- 最便宜的证伪实验：固定切分比较少量深度/树数，检查训练—验证差距和特征缺失处理。
- 与哪些方法公平比较：线性模型、朴素预测和时序模型使用同一切分、调参预算和指标。
- 常见失败模式：小样本过拟合、把 target encoding 拟合到全数据、时间特征穿越、重要性被误读。
- 论文中可以声称什么：在指定数据和验证协议下的非线性预测表现或稳定性。
- 论文中不能直接声称什么：特征重要性是因果影响、树模型必然优于线性模型，或对未来分布保证泛化。

## 分类与类别不平衡

- 适用信号：正负样本比例悬殊，漏报、误报和阈值成本不对称。
- 核心变量或对象：标签 \(y\in\{0,1\}\)、预测概率 \(p\)、阈值 \(t\)、混淆矩阵和类别权重。
- 基本数学形式：最小化加权交叉熵或在约束召回率下选择阈值，报告 precision、recall、F1、PR-AUC 等。
- 最小 baseline：多数类、分层抽样下的常数概率和一个逻辑回归。
- 最便宜的证伪实验：固定测试集，画阈值—召回—精确率曲线，并比较 class weight/重采样是否改变结论。
- 与哪些方法公平比较：统一分层切分、阈值选择规则、代价矩阵和主要指标。
- 常见失败模式：只报 accuracy、在测试集调阈值、重采样越过切分边界、概率未校准。
- 论文中可以声称什么：指定阈值、样本比例和代价下的分类表现及取舍。
- 论文中不能直接声称什么：高 accuracy 等于识别能力强、概率就是事件真实概率，或阈值适用于所有场景。

## 聚类 / 无监督分群

- 适用信号：没有可靠标签，但需要发现群体结构、异常子群或运营分层。
- 核心变量或对象：特征矩阵 \(X\)、距离/相似度、簇分配 \(z_i\) 和簇数 \(K\)。
- 基本数学形式：K-means 最小化 \(\sum_i\|x_i-\mu_{z_i}\|^2\)；也可比较层次聚类或密度方法。
- 最小 baseline：按业务规则分层或 K-means 的少量 \(K\) 值。
- 最便宜的证伪实验：标准化前后比较轮廓系数、簇稳定性和小扰动下的成员变化。
- 与哪些方法公平比较：相同特征、缩放、缺失处理、距离定义和随机重启预算。
- 常见失败模式：量纲支配距离、把簇编号当有序标签、用同一数据选择 \(K\) 后夸大发现、簇不可复现。
- 论文中可以声称什么：在特定特征空间和距离下的分组结构及其描述性差异。
- 论文中不能直接声称什么：簇是自然真实类别、分群具有因果意义，或无监督簇必然可用于决策。

## 时间序列与时间外验证

- 适用信号：观测具有时间顺序、滞后、趋势、季节性或滚动预测任务。
- 核心变量或对象：时间 \(t\)、历史窗口、滞后特征、趋势/季节项和预测区间。
- 基本数学形式：\(\hat y_{t+h}=f(y_{\le t},x_{\le t})\)，可比较 naive、指数平滑、ARIMA、状态空间或时序特征模型。
- 最小 baseline：last-value、seasonal-naive 或滚动均值。
- 最便宜的证伪实验：用最后一段做时间外测试，再与随机切分对照以暴露泄漏。
- 与哪些方法公平比较：相同 forecast horizon、滚动窗口、可用信息截点和误差指标。
- 常见失败模式：随机切分穿越未来、滚动统计用了测试期、发布日期与观测期混淆、缺失时间点被忽略。
- 论文中可以声称什么：指定预测窗口和时间外验证上的误差及稳定性。
- 论文中不能直接声称什么：对结构变化后的长期未来保证准确，或把时间相关误差解释成因果关系。

## 不确定性与概率校准

- 适用信号：决策需要风险边界、预测区间、事件概率或希望知道模型何时不可靠。
- 核心变量或对象：预测均值/分位数、区间 \([l,u]\)、概率 \(p\)、覆盖率和 sharpness。
- 基本数学形式：区间覆盖率 \(P(y\in[l,u])\)、Brier score、log loss、分位数损失或 conformal 区间。
- 最小 baseline：经验分位数、常数区间或未校准分类概率。
- 最便宜的证伪实验：在时间外或独立留出集上画 calibration curve，比较覆盖率与区间宽度。
- 与哪些方法公平比较：相同校准集、置信水平、预测窗口和评价损失。
- 常见失败模式：用测试集校准、把名义置信度当实际覆盖、忽略分布漂移和样本依赖。
- 论文中可以声称什么：在指定数据和覆盖评价下的经验不确定性表现。
- 论文中不能直接声称什么：对未来任意分布有概率保证，或把校准等同于模型正确。

## 可解释性与泄漏检查

- 适用信号：需要解释模型、定位风险，或题面数据可能包含未来字段、重复实体和答案代理变量。
- 核心变量或对象：特征生成时间、训练拟合范围、置换/局部贡献、实体键和标签构造路径。
- 基本数学形式：在不改变评估协议的前提下比较置换重要性、部分依赖或局部解释，并记录泄漏路径。
- 最小 baseline：移除疑似泄漏字段后重跑一个可解释模型，与原结果对照。
- 最便宜的证伪实验：打乱标签、复制测试实体或把未来字段加入模型，确认检查器能发现异常提升。
- 与哪些方法公平比较：同一切分、同一预处理拟合范围和同一解释样本；解释不是额外的性能赛道。
- 常见失败模式：把相关当因果、解释工具看到了测试数据、重要性随切分剧烈漂移、泄漏结果仍进入正文。
- 论文中可以声称什么：在指定模型和样本上的关联性解释、稳定性和已检查的泄漏边界。
- 论文中不能直接声称什么：解释证明因果、重要性是唯一机制，或一次审计足以证明没有所有泄漏。
