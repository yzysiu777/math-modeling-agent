# 运筹优化实战方法卡

这些卡片用于在读题后快速生成方法论不同的候选路线。最终路线由题面、最小实验和
队员判断决定。

## 线性规划 / 混合整数规划（LP/MIP）

- 适用信号：资源分配、选址、排班、装载或流程关系大体线性，且有连续、整数或二元决策。
- 核心变量或对象：决策向量 \(x\)、二元变量 \(y\)、资源约束矩阵 \(A\) 和右端 \(b\)。
- 基本数学形式：\(\min c^\mathsf{T}x\)，满足 \(Ax\le b\)、\(x\in\mathbb{R}^n\) 或 \(\mathbb{Z}^n\)，并补充逻辑约束。
- 最小 baseline：按单位成本排序的贪心规则，或连续松弛的下界。
- 最便宜的证伪实验：在可手算的小实例上与穷举比较可行性和目标值。
- 与哪些方法公平比较：贪心、网络算法、动态规划或元启发式使用同一实例、约束和时间预算。
- 常见失败模式：漏约束、错误的大 \(M\)、单位不一致、不可行状态没有诊断、把 solver 的可行解写成全局最优。
- 论文中可以声称什么：在明确的数学模型和求解状态下得到的可行解、下界或最优性证明。
- 论文中不能直接声称什么：现实系统一定最优、未建模因素不影响结论，或启发式结果是全局最优。

## 网络最短路 / 最小费用流

- 适用信号：对象可表示为节点和边，成本、容量、流守恒或路径连通性是核心关系。
- 核心变量或对象：有向图 \(G=(V,E)\)、边成本 \(c_{ij}\)、容量 \(u_{ij}\)、路径或流量 \(f_{ij}\)。
- 基本数学形式：最短路为 \(\min\sum_{(i,j)\in E}c_{ij}x_{ij}\)；最小费用流另加节点流守恒和容量约束。
- 最小 baseline：BFS（无权图）或按边权的 Dijkstra；先在小图上画出路径。
- 最便宜的证伪实验：构造负边、不可达点、并列最短路和容量饱和的小图检查边界。
- 与哪些方法公平比较：A*、整数规划或随机路径方法使用同一图、起终点、权重和不可行处理。
- 常见失败模式：负权仍调用 Dijkstra、忘记方向或障碍、路径节点重复、容量/流守恒实现错误。
- 论文中可以声称什么：在给定图、权重和算法假设下的最短路或最小费用流结果。
- 论文中不能直接声称什么：图外真实距离最短、动态环境下仍然最优，或未验证的复杂度和可达性。

## 动态规划（DP）

- 适用信号：决策可按阶段展开，具有有限状态、递推关系和最优子结构。
- 核心变量或对象：阶段 \(t\)、状态 \(s_t\)、动作 \(a_t\)、转移 \(s_{t+1}=T_t(s_t,a_t)\) 和价值函数 \(V_t(s)\)。
- 基本数学形式：\(V_t(s)=\min_{a\in\mathcal A_t(s)}\{g_t(s,a)+V_{t+1}(T_t(s,a))\}\)。
- 最小 baseline：贪心或逐阶段局部最优规则。
- 最便宜的证伪实验：枚举两到三个阶段的全部策略，逐项核对递推和回溯路径。
- 与哪些方法公平比较：小规模穷举、MIP 或 beam search 使用相同状态边界和目标。
- 常见失败模式：状态缺少未来决策所需信息、转移遗漏、边界条件错误、状态空间爆炸。
- 论文中可以声称什么：在状态定义满足最优子结构且递推覆盖所有可行动作时的精确结果。
- 论文中不能直接声称什么：任意压缩状态都保持最优，或大规模运行仍能在未说明资源下完成。

## 排程与资源约束调度

- 适用信号：任务有先后关系、机器/人员容量、处理时间、交付期或切换成本。
- 核心变量或对象：任务开始时间 \(s_i\)、机器分配 \(y_{im}\)、完成时间 \(C_i\)、优先关系和资源占用。
- 基本数学形式：最小化最大完工期、总迟延或加权成本，并加入 precedence、capacity 和 non-overlap 约束。
- 最小 baseline：最早交期、最短处理时间或拓扑序 + 空闲资源的派工规则。
- 最便宜的证伪实验：两台机器、少量任务的穷举排程，检查重叠、先后和完工时间。
- 与哪些方法公平比较：MIP、CP-SAT、局部搜索或遗传算法在相同任务集、时间限制和惩罚定义下比较。
- 常见失败模式：先后关系方向反转、时长单位混用、资源冲突漏检、迟延目标和完工目标混淆。
- 论文中可以声称什么：在给定资源与优先约束下的可行排程及其目标表现。
- 论文中不能直接声称什么：未验证的生产现场可执行性、对扰动完全鲁棒，或启发式全局最优。

## 分解与松弛

- 适用信号：模型规模大但具有块结构、耦合约束少，或可先求下界再协调子问题。
- 核心变量或对象：主问题变量、子问题变量、耦合约束、拉格朗日乘子或 Benders cuts。
- 基本数学形式：把耦合约束移入惩罚项，或以主问题决定连接变量、子问题验证可行性并生成割。
- 最小 baseline：完整小规模 MIP 或连续松弛，作为质量和下界参照。
- 最便宜的证伪实验：在可求精确的小实例上比较分解上下界、迭代收敛和最终可行性。
- 与哪些方法公平比较：直接 MIP、固定迭代预算的分解算法和简单启发式。
- 常见失败模式：割/乘子方向错误、上下界没有统一、子问题不可行未处理、停止条件过早。
- 论文中可以声称什么：在明确停止准则下的可行解、上下界和相对 gap。
- 论文中不能直接声称什么：没有 gap 或收敛证据却宣称全局最优，或把分解速度优势推广到所有规模。

## 启发式 / 元启发式

- 适用信号：精确模型过大、目标非光滑或需要快速给出可行方案，且允许近似。
- 核心变量或对象：解编码、邻域、构造/扰动算子、温度或群体、可行性修复和停止准则。
- 基本数学形式：以 \(x^{(k+1)}\in\mathcal N(x^{(k)})\) 的邻域搜索或群体更新近似求解 \(\min f(x)\)。
- 最小 baseline：随机可行解、贪心构造或局部搜索。
- 最便宜的证伪实验：小实例与穷举最优值比较，多随机种子重复并记录可行率和波动。
- 与哪些方法公平比较：相同初始解预算、运行时间、约束修复规则和重复次数。
- 常见失败模式：不可行修复掩盖真实约束、只报告最好一次、随机种子未记录、参数调到测试集。
- 论文中可以声称什么：在指定预算、实例和重复试验下的经验最好解或平均表现。
- 论文中不能直接声称什么：全局最优、稳定优于所有方法，或一次运行结果具有普遍性。

## 多目标优化

- 适用信号：成本、服务、风险、时效等目标存在冲突，单一权重不能充分表达取舍。
- 核心变量或对象：目标向量 \(F(x)=(f_1(x),\ldots,f_k(x))\)、权重、归一化尺度和 Pareto 集。
- 基本数学形式：加权和、ε-constraint 或 Pareto 支配；必须明确目标方向和尺度。
- 最小 baseline：单目标方案、几个透明权重组合或固定一个目标的约束法。
- 最便宜的证伪实验：改变一个权重/阈值，画出两目标 trade-off 并检查是否出现支配解。
- 与哪些方法公平比较：相同归一化、可行域、求解预算和选择偏好。
- 常见失败模式：量纲未归一、权重含义不清、把非支配点全部称为同等好、忽略偏好变化。
- 论文中可以声称什么：给定偏好或约束下的折中方案、非支配关系和敏感性。
- 论文中不能直接声称什么：不存在唯一“最佳”方案却强行给出普适最优，或把权重选择当客观事实。

## 鲁棒 / 随机优化

- 适用信号：需求、时间、成本或成功概率不确定，决策需要在扰动下保持服务或风险边界。
- 核心变量或对象：不确定参数 \(\xi\)、场景集合/分布、置信集合、决策 \(x\) 和 recourse \(y(\xi)\)。
- 基本数学形式：鲁棒为 \(\min_x\max_{\xi\in\mathcal U} f(x,\xi)\)；随机为最小化期望成本并约束概率或风险。
- 最小 baseline：确定性均值/中位数方案 + 事后压力测试。
- 最便宜的证伪实验：两到三个极端场景比较成本、可行性和服务水平。
- 与哪些方法公平比较：相同场景、样本、风险度量、时间预算和服务约束。
- 常见失败模式：不确定集合过宽或过窄、场景概率未经校准、把压力测试误称概率保证。
- 论文中可以声称什么：在指定不确定集合或场景分布下的风险/服务表现。
- 论文中不能直接声称什么：对未覆盖分布的保证、现实概率准确，或鲁棒一定优于确定性方案。
