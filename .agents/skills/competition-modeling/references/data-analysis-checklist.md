# 数据分析检查清单

- [ ] 数据来源、文件大小、实体粒度、主键和连接关系已记录；普通数据 SHA-256 可选，需冻结时再记录
- [ ] 字段含义、单位、编码、缺失和异常范围已记录
- [ ] 重复样本、重复实体和时间顺序已检查
- [ ] 标签生成不使用答案、未来信息或测试信息
- [ ] 训练/验证/测试按研究对象和时间边界正确隔离
- [ ] 预处理、特征选择和模型选择只在允许的数据范围内拟合
- [ ] 简单统计/预测 baseline 可运行且指标明确
- [ ] 指标、置信区间、校准、类别不平衡和误差分解与任务匹配
- [ ] 中间量指标与最终交付指标同时报告；参数选择期与评估期分别写明，重叠时已标注偏乐观
- [ ] 交叉验证/留出/时间外验证和随机种子已记录
- [ ] 稳定性、敏感性、消融或亚组分析已完成
- [ ] 关联、预测重要性、解释和因果表述边界清楚
- [ ] 缺失、异常、偏差和推广边界进入结论限制
