# 官方论文文件清单

本目录保存每届官方文件的版本清单，不自动把社区 LaTeX 模板变成官方文件。

比赛日操作：

1. 从官方赛事网站下载当届论文标准文档、模板、封面、摘要页和 AI 规定；
2. 复制原文件到 `paper/official/<year>/`；
3. 在该目录的 `manifest.yaml` 记录 URL、发布日期、下载日期、大小、SHA-256、是否当前有效；
4. 在 `paper/config/paper-profile.tex` 更新年份、封面路径和字体配置；
5. 编译、渲染、人工核验后，才允许把 PDF 当作提交候选。

当前工作台默认使用 CI 可携带字体和内部占位封面，明确不能直接提交。
