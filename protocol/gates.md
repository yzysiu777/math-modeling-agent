# 华为杯固定竞赛 Gate 合同

本文件是团队可读的门禁说明；机器可读定义位于
`scripts/gate_contract.py`。工作台只有这一套 G0–G12，不按题目或速度
切换流程。

## 统一 Gate 编号

| Gate | 名称 | 进入状态 | 首次通过的退出证据 |
|---|---|---|---|
| G0 | 目标、题意与权限 | `routed` | 人工确认目标、交付物和权限边界 |
| G1 | 输入和数据冻结 | `frozen` | 输入清单、来源、只读状态和 SHA-256 |
| G2 | 数据契约、假设、符号和指标 | `contracted` | 数据/模型契约、假设表和指标定义 |
| G3 | Baseline | `baseline_ready` | 可解释 baseline、小案例和运行记录 |
| G4 | 正式模型和算法 | `model_ready` | 公式、算法、代码版本和参数记录 |
| G5 | 正确性、可行性与边界 | `validated` | 手算/穷举、维度、约束和边界检查 |
| G6 | 结果可信度与稳健性 | `results_verified` | 对照、复算、敏感性和稳健性证据 |
| G7 | 独立审核 | `reviewed` | C1/C2/C3 审核记录和未解决问题 |
| G8 | 修订与回归 | `gate_passed` | 变更影响、定向验证和关闭记录；无修订时记录“无待回归变更” |
| G9 | 论文证据绑定 | `paper_ready` | claim—实验—图表—引用映射 |
| G10 | 官方格式和 AI 合规 | `format_checked` | 当届规则、匿名和 AI 记录预检 |
| G11 | LaTeX/PDF 检查 | `pdf_qa_passed` | 编译、文本、元数据、渲染和 PDF 哈希 |
| G12 | 人工冻结 | `human_frozen` | 人工 signoff、最终提交文件和版本冻结 |

## 状态裁决

- `PASS`：退出证据完整，没有已知阻断项；
- `PASS_WITH_LIMITATIONS`：允许继续，但限制必须进入 claim、论文和交接；
- `BLOCKED`：存在 P0/P1 或关键证据缺失，停止推进；
- `REJECTED`：当前路线被题面、数据、推导、反例或复现否定；
- `PENDING`：检查已开始但退出证据尚未齐全。

P0/P1 问题不能靠两个模型意见一致而关闭。G12 必须由人工完成。

## 影响范围的最低约束

| 变更级别 | 允许影响的最低范围 | 明确不自动触发 |
|---|---|---|
| R0 | 普通文字/非实质排版；若改 `.tex`，只做快速编译 | 实验复跑、Claude 审核、claim 重新审核、完整 PDF QA |
| R1 | 论文数字、结论、图表、引用及其证据绑定 | 全量实验重跑、模型重建 |
| R2 | 代码、参数、随机种子、实验流程及相关结果/claim | 与变更无关的实验 |
| R3 | 数据、标签、切分、公式、目标、约束、核心算法及其下游证据 | 任何“代码能运行即可恢复”的捷径 |

实际影响以 `change_impact_record.affected_*` 为准，但不得小于脚本给出的
最低范围。验证清单只记录安全检查 ID，不记录或执行 YAML 中的任意命令。

## 通过规则

1. G1/G2 不通过，不能比较复杂模型或训练复杂模型。
2. G3 不通过，不能声称复杂方法带来提升。
3. G5 不通过，不能报告满足约束的可靠结果或最优性结论。
4. G6 不通过，不能把单次输出写成稳定结论。
5. G7 存在未解决 P0/P1，不能进入论文定稿。
6. G8 的每一项 required check 都必须有执行证据和退出码。
7. G9/G10/G11 任一不通过，不能提交论文。
8. G12 不能由 Codex、Claude 或确定性脚本代签。
