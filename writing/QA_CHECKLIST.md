# 论文质量检查清单

## 内容

- [ ] 题面全部子问有明确章节和输出。
- [ ] 摘要有对象、方法、模型、关键结果、结论、贡献/限制和关键词。
- [ ] 每个子问完成分析—假设—模型—求解—结果—检验闭环。
- [ ] 主要数字可定位到 claim、实验、结果表或代码输出。
- [ ] 结论没有超出数据、假设和验证范围。

## 数学与算法

- [ ] 目标函数、变量、参数、约束、单位和边界已定义。
- [ ] 论文公式与代码实现逐项对照。
- [ ] 有 baseline、对照、小规模测试或严格求解器证据。
- [ ] 随机算法记录种子、重复次数和波动；优化算法记录可行性和停止条件。
- [ ] “最优、显著、导致、稳定、创新”等词有对应证据，否则已降级。

## 数据与结果

- [ ] 原始输入只读并有来源、大小和数据字典；普通数据哈希可选，需要冻结的版本再记录。
- [ ] 切分、时间边界、标签和预处理没有泄漏。
- [ ] 结果表无手工抄写错误、单位混用或小数位混乱。
- [ ] 图表轴、单位、图例、范围和误差说明齐全。
- [ ] 敏感性、稳健性、失败路线和适用边界已记录。

## 引用与 AI

- [ ] 正文外部事实、公式、算法、数据、代码和图片有对应引用。
- [ ] `.bib`、正文编号和参考文献顺序一致。
- [ ] 来源、版本、URL/DOI、访问日期可核验。
- [ ] AI 使用记录完整，采纳内容有人工核验证据。
- [ ] 当届规则要求的 AI 声明已放在正确位置。

## LaTeX 与 PDF

- [ ] XeLaTeX + BibTeX 完整编译（`make paper-ci`），无未解析引用和交叉引用。
- [ ] `config/paper-profile.tex` 中的「待填写」已全部替换，承诺书页与标题页字段正确。
- [ ] 已在准备提交的那台机器上重编一次（CI 用 fandol 字体，行距与断行会有差异）。
- [ ] 图题在图下、表题在表上，所有图表公式正文均有引用。
- [ ] 页面、摘要、字体、行距、页码、匿名性和元数据符合当届规则。
- [ ] PDF 经过文本、文件类型、元数据和页面渲染检查。
- [ ] 最终 PDF 已计算 SHA-256/MD5，并由队员人工确认提交版本。
