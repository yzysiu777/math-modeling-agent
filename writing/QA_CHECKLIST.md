# 论文质量门禁

## G7-A 内容完整性

- [ ] 题面所有子问在正文中有明确对应章节。
- [ ] 摘要包含思路、方法、模型、结果、结论、创新点和关键词。
- [ ] 每个问题完成“分析—假设—模型—求解—结果—检验”闭环。
- [ ] 论文中的主要数字都能定位到结果表、实验记录或代码输出。
- [ ] 结论没有超出数据、假设和验证范围。

## G7-B 数学与算法

- [ ] 所有目标函数、变量、参数、约束、单位和边界条件已定义。
- [ ] 论文公式与代码实现逐项对照。
- [ ] 有 baseline、对照实验或小规模可验证实例。
- [ ] 随机算法记录种子、重复次数和波动；优化算法记录可行性和停止条件。
- [ ] “最优”“显著”“导致”“稳定”等强词有对应证据，否则已降级措辞。

## G7-C 数据与结果

- [ ] 原始数据只读，记录文件哈希和字段字典。
- [ ] 切分、时间窗口、训练/测试边界和缺失值处理无泄漏。
- [ ] 结果表没有手工抄写错误、单位混用或小数位混乱。
- [ ] 图表轴、单位、图例、数据范围和误差说明齐全。
- [ ] 2023 E 不把关联写成因果；2019 F 不把启发式写成全局最优；2025 A 不把未验证调度写成可行最优。

## G7-D 引用与 AI

- [ ] 正文每个外部事实、公式、算法来源都有对应 [n]。
- [ ] 参考文献按正文首次引用顺序排列，URL 可访问，访问日期齐全。
- [ ] 引用代码、数据、博客和开源仓库时明确来源和版本。
- [ ] 已按当届规则决定 AI 声明位置和内容。
- [ ] AI 工具名称、版本/型号、机构、日期、用途、采纳和核验均有记录。

## G7-E 官方版式

- [ ] 使用当届官方封面、Logo、统一摘要页和标准文档。
- [ ] 摘要页页数符合当届要求，页码从指定页开始并居中。
- [ ] 无页眉；非封面页面无学校、姓名、队号或其他身份信息。
- [ ] 题目、一级标题、正文汉字、行距符合当届规范。
- [ ] 图题在图下，表题在表上，公式/图/表无断号。
- [ ] PDF 可以正常打开，字体未丢失，公式未乱码，图表无裁切和越界。
- [ ] 最终 PDF 与提交前生成 MD5 的文件完全一致。

## G7-F 视觉验收

必须把最终 PDF 渲染为 PNG 后逐页检查，至少覆盖：

1. 封面；
2. 摘要页第一页和最后一页；
3. 目录页；
4. 每个问题的第一张图/表/公式页；
5. 参考文献；
6. 附录首页和最后一页。

发现页码漂移、公式断裂、图表越界、空白页、字体替换或匿名性问题时，状态为 BLOCKED，不能提交。

## 结果状态

~~~text
PASS                  通过，无已知阻断项
PASS_WITH_LIMITATIONS 允许继续，但限制必须写进论文
BLOCKED               P0/P1 或官方格式不合规
PENDING               证据尚未完成
~~~
