# 固定论文结构与推荐版式

本文件是团队内部内容标准；当届官方要求与它冲突时，官方规则优先。

## 推荐骨架

```text
官方封面
统一摘要页：题目、摘要、关键词
正文
1 问题重述
2 问题分析与总体技术路线
3 模型假设与符号说明
4 子问题一：分析、模型、求解、结果、检验
5 子问题二：分析、模型、求解、结果、检验
...按题面实际子问增删...
综合评价、敏感性、稳健性与推广
结论与建议
参考文献
AI 工具使用说明（按当届规则放置）
附录：支撑材料、命令、证明和补充结果
```

不要为了固定章节数拆分没有独立内容的章节；每个子问都应形成“分析—假设—模型—求解—结果—检验—限制”闭环。

## 摘要结构

依次写研究对象与总目标、各子问题的方法链和关键结果、整体贡献/适用边界、关键词。摘要数字必须和结果表、实验记录逐项一致；未经 G7/G10 通过的数字只能标记为待验证。

## 内部默认版式

这些是 LaTeX 默认值，不替代官方标准：

| 元素 | 默认约定 |
|---|---|
| 纸张 | A4 |
| 中文 | `ctex` 默认可携带字体；正式版由当届模板指定 |
| 英文/数字 | 与中文字体兼容的拉丁字体 |
| 行距 | 单倍，按官方模板校准 |
| 页眉 | 默认无 |
| 页脚 | 居中连续页码，起始页按官方规则 |
| 图题 | 图下方 |
| 表题 | 表上方 |
| 公式 | 全文统一编号并在正文引用 |
| 引用 | 顺序编码制 `[1]`，由 `.bib` 管理 |

不要在源文件中写死本地商业字体名称；CI 使用可携带字体，正式发布用比赛日机器执行字体预检。

## 竞赛论文风格

所谓“国奖语言”在本工作台中指：问题对应完整、模型假设透明、baseline 清楚、结论有证据、限制具体、图表服务论证、叙述克制。它不是固定词典，也不是堆砌公式或夸张形容词。
