# 竞赛论文语言规范：把“国奖语言”变成可检查规则

组委会没有公布一份名为“国奖语言”的固定词典。这里的规则来自官方评审关注的假设合理性、建模创造性、结果正确性、文字规范性，以及本地高奖论文的稳定表达方式。它是写作建议，不冒充官方术语表。

## 1. 基本句式

优先使用“对象—动作—证据—边界”的句式：

~~~text
在【数据/约束/评价指标】下，本文采用【模型/算法】求解【目标】。
在【验证方案】中，该方法得到【结果】，相较【基线】变化为【数值】；该结论仅适用于【范围/假设】。
~~~

推荐动词：

- 问题重述：研究、刻画、判断、预测、规划、调度、评估；
- 模型建立：定义、构造、建立、表示、刻画、约束；
- 算法：求解、迭代、搜索、更新、收敛、停止；
- 证据：表明、支持、与……一致、在……下验证；
- 局限：依赖、适用于、不能排除、尚未验证、可能受……影响。

## 2. 必须区分的结论强度

| 不要直接写 | 应改为 | 使用条件 |
|---|---|---|
| 最优解 | 满足约束的可行解 / 当前算例中的最优解 / 求解器给出的最优解 | 只有有证明或求解器最优性证书时才写全局最优 |
| 证明了某因素导致结果 | 观察到该因素与结果相关 / 在预测模型中贡献较高 | 需要因果识别设计才可使用“导致” |
| 模型准确率很高 | 在指定切分和指标下，模型达到…… | 同时给数据切分、指标和区间/波动 |
| 显著提高 | 相比基线提高……；差异在……检验下显著 | 给出基线、样本、检验和效应量 |
| 结果稳定 | 在……个随机种子/折次/扰动下结果范围为…… | 没有稳定性实验时写“本次运行得到” |
| 误差为 0 | 在当前精度和测试集上未观察到误差 | 不把有限样本结果写成绝对真理 |
| 创新性强、效果优秀 | 提出……；相较……减少/增加…… | 用具体技术变化和证据替代评价词 |

## 3. 禁用或高风险表达

未经证据不得使用：

完美、绝对准确、显然最优、完全解决、业内领先、效果非常好、显著优于所有方法、必然、一定导致、无任何缺点、具有重大意义、创新性极强。

这些词不是绝对不能出现，而是必须有严格的定义、对照、统计检验或理论证明。默认由写作审查者标红。

## 4. 摘要语言

摘要避免三类问题：

1. 背景超过方法和结果；
2. 只堆模型名称，不说明模型解决了什么困难；
3. 数字和正文不一致，或把未经复现的候选结果写成最终结果。

推荐段落模板：

~~~text
本文针对……问题，在……数据/约束下，建立……。
针对问题一，先……，再……，最终在……验证下得到……。
针对问题二，……。
针对问题三，……。
结果表明，在……范围内，……；模型的主要限制是……。
~~~

## 5. 医疗、关联与因果

2023 E 中尤其执行以下替换：

- “治疗方法对预后有正向作用” → “在本数据和控制变量/模型设定下，治疗变量与预后预测值呈正向关联”。
- “高血压导致血肿扩张” → “高血压变量在该预测模型中具有较高重要性/与血肿扩张风险呈关联”。
- “模型可以指导临床决策” → “模型可为……场景提供辅助信息，仍需临床验证”。

## 6. 结果段落的最小信息

每个关键结果至少包含：

- 对象/数据集；
- 指标定义；
- 基线或对照；
- 数值和单位；
- 不确定性或稳定性信息；
- 解释边界。

## 7. 人工审查问题

写作完成后逐句问：

1. 这句话的主语是什么？
2. 它是事实、推导、实验观察、模型解释还是建议？
3. 证据在哪里？
4. 证据是否支持这么强的语气？
5. 如果删掉形容词，结论是否仍然成立？
