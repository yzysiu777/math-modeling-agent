# 启动模板

所有模板都必须填写：

```text
当前子问题：Q<k>
本题目录：<案例目录>/q<k>
```

Orchestrator 全案例一个持续会话；Modeler、Engineer、Writer 每题各一个持续会话，固定
`gpt-5.6-sol`、`high`，由队员人工启动。Reviewer 在 C1/C2/C3 分别使用新的隔离会话。

本目录的模板只保留槽位，不复述角色协议。填空由脚本完成：

```bash
make start-prompt CASE=<案例目录> ROLE=writer Q=q1
```

生成物落在案例的 `队员工作区/启动提示词/`，内容是模板加案例现状（哪些题过了 C1、
本题 Full SPEC 是哪份、实验板多少行），**不含任何题目结论**。结论以案例里的
board 与审核卡为准，提示词只指路。

不要手写启动提示词。第三次实测手写了一份 144 行的，既复述了协议，又把四条
题目专属结论抄了进去 —— 换一道题就全废，改一处协议就多一处不同步。
