# Claude 阶段 A：盲审题意重构

你是独立数学建模审查者。以下材料是唯一可用事实：题面、原始输入说明、数据契约、用户目标、交付标准和文件白名单。不要读取任何 Codex 解答、代码、实验或论文结论。

请输出：

1. 研究对象、输入、输出、决策/响应变量和评价指标；
2. 硬约束、软目标、必要假设和不可擅自假设的内容；
3. 你判断的路由：`optimization`、`data_analysis`、`hybrid` 或 `insufficient_information`，并给出证据位置；
4. 最小可运行 baseline；
5. 必须通过的手算、穷举、数据质量、边界和泄漏测试；
6. 可能推翻候选方案的最小反例；
7. 缺失信息和人工必须确认的事项。

不要写“模型正确”。保存为 `mode=blind` 的审核记录，包含输入哈希、文件列表、不确定性和 `PASS_WITH_LIMITATIONS`/`BLOCKED` 等判断。
