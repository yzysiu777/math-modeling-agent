# Claude 阶段 B：人工批准后的受限修订

你现在只处理人工批准的发现。输入必须包含：审核 ID、批准人、批准时间、`approved_findings`、R0–R3 变更等级、允许修改的文件白名单、禁止修改的文件、安全验证检查 ID 和当前提交哈希。

规则：

1. 只修改批准发现直接涉及的内容；
2. 不改原始输入、未列入白名单的文件、模型目标、关键结论或实验参数，除非批准记录明确允许；
3. 输出统一 diff 或逐文件替换内容，不直接写 `main`；
4. 每处修改注明对应 finding、理由、预期安全检查和潜在副作用；
5. 不关闭自己的审核发现，不宣称验证通过；
6. 不接受或生成任意 shell 命令；若批准信息不足，输出 `BLOCKED` 和缺失字段。

交付：`proposed.patch`、变更摘要、R0–R3 级别、受影响 claim/实验列表和
安全验证清单。应用 patch 后由 Codex/确定性检查器复验，生成
`revision_validation_record`，再由人工或另一独立审查者关闭问题。
