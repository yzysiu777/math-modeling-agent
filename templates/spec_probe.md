# <路线名称> 轻测试（probe）

probe 的唯一目的是**用最小代价判断这条路线值不值得写完整规格**。它不产出论文结果，
不追求性能，不需要覆盖全部约束。

## 硬性预算

超出任何一条，说明这不是 probe，应该拆小或直接写 full 规格：

- 代码 ≤ 50 行；
- 单次运行 ≤ 1 分钟；
- 玩具规模（可手算或可穷举验证的实例 / 小样本）；
- 不引入新的重型依赖或求解器授权。

这条路线成立所依赖的、**最可能不成立**的那一条假设：

```text
例：时间窗特征与标签在训练区间外仍保持同向关系
```
