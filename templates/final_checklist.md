# 竞赛提交前检查清单

## 题意与模型

- [ ] 题面、附件和字段含义已由队员核对
- [ ] 每题 C1 卡有节点决定并写明推荐路由，或使用人工覆盖
- [ ] 每个子问题有目标、变量/响应、约束、单位和评价指标
- [ ] Champion 与 Challenger 的比较口径一致
- [ ] 失败路线和关键假设已记录

## 数值与代码

- [ ] 数据切分、标签、时间顺序和泄漏已检查
- [ ] 优化解通过独立可行性检查
- [ ] 优化目标值和关键统计指标已重算
- [ ] 小规模/边界/极端实例已测试
- [ ] 随机种子、参数、代码入口和环境已记录
- [ ] 结果、图表和论文数字来自同一实验记录

## Independent Reviewer 与人工

- [ ] 每题的 C1、C2、C3 与全案例收官 C3 已完成并保存
- [ ] 审核报告已注明 provider、model、`review_session: fresh`、`saw_main_conversation: false` 和 critical node
- [ ] `decisions.md` 只记录人工专属边界决定
- [ ] `make case-check CASE=... STAGE=paper_claims` 已运行且没有阻断项
- [ ] 未检查内容、不确定性和限制已进入论文或交接
- [ ] Reviewer 推荐动作已实施或由队员明确否决；最终提交已由人工确认

## 论文与提交

- [ ] 公式、代码、图、表、引用和结论一致
- [ ] 摘要只包含可追溯数字和校准后的结论
- [ ] 当届官方模板、匿名规则、字体、页数和 AI 规定已重新核对
- [ ] XeLaTeX 编译、引用、PDF 文本和版式检查通过
- [ ] `make final-check CASE=...` 已运行且案例、C3、人工决定和 PDF QA 均通过
- [ ] 最终 PDF 由队员人工打开检查并确认提交文件
