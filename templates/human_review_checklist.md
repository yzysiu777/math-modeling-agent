# 一页式人工审核清单

这张清单与 `human_review_card.yaml` 一起使用。人工只需确认真正看过的
内容；程序和 Claude 已检查的内容不能冒充人工检查。

## C1：题意、目标和约束

- [ ] 我逐条回看了题面中的输入、输出和交付要求。
- [ ] 我确认了硬约束、软目标、单位、时间边界和评价指标。
- [ ] 我看过 Claude 给出的替代解释和最小反例。
- [ ] 我明确记录了未检查内容和需要题目负责人决定的歧义。

## C2：模型架构和算法

- [ ] 我确认变量、目标、约束和关键公式确实对应题意。
- [ ] 我看过公式—代码映射和一个小规模/极端测试。
- [ ] 我理解当前方法族与替代方法族的差异及主要取舍。
- [ ] 我明确知道哪些可行性、最优性或复杂度问题仍需专业队员把关。

## C3：主要结果和论文强结论

- [ ] 我抽查了 3–5 个最重要数字、结论或图表的证据链。
- [ ] 我确认核心约束/指标有局部复算，且 baseline 对照公平。
- [ ] 我看过数据泄漏、选择性报告、稳定性和适用边界风险。
- [ ] 我确认论文没有把启发式写成最优、关联写成因果或单次写成稳定。

## 共同签字前确认

- [ ] `human_checked`、`human_not_checked` 和 `expertise_limitations` 已填写。
- [ ] 接受、拒绝、退回或升级的决定及后续动作已记录。
